================================================================================
TECHNOLOGY TRANSFER MANAGEMENT SYSTEM (TTMS)
Full Project Plan
Client: Technology Transfer Office (TTO), North South University, Dhaka
================================================================================

AGREED TECH STACK
-----------------
Framework    : Laravel (PHP)
Templating   : Laravel Blade (what the developer already knows)
UI / CSS     : Tailwind CSS
Reactivity   : Livewire (reactive PHP components, Blade-based — no JSON API)
               Alpine.js (15kb JS, adds simple interactivity to Blade templates)
Admin Layout : Custom-built with Blade + Tailwind (no heavy admin shell)
Tables       : DataTables.js (server-side paginated tables, familiar plain JS)
Charts       : Chart.js (plain JS, for analytics/dashboards)
Build Tool   : Vite (ships with Laravel)
Database     : MySQL (via Laragon)
File Storage : Laravel Storage (local disk)
Email        : Laravel Mail + Queue (MailHog via Laragon for local dev)
PDF Export   : barryvdh/laravel-dompdf
Excel Export : maatwebsite/excel

WHY THIS STACK
--------------
- Everything stays in Blade — no separate JS framework to learn
- Livewire components are just PHP classes + Blade files (very familiar)
- Alpine.js adds dropdowns, modals, toggles with simple HTML attributes
- No Filament overhead — the admin layout is your own Blade templates
- DataTables.js and Chart.js are plain JS plugins you can use directly
- Fast in both development and production

PHASE 3 — Invention Disclosure Module
================================================================================

Form sections (Livewire multi-step form):
  A. Inventor Information    (Name, Designation, Department, Contact)

PHASE 4 — Workflow Management System
================================================================================
Goal: Automated status transitions with email notifications at each step.

Workflow 1 — Invention Disclosure:
  Research Created → Disclosure Submitted → TTO Review →
  Ownership Determination → Patentability Evaluation →
  IP Committee Review → Decision → Patent Filing → Commercialization

Workflow 2 — Ownership Determination:
  Disclosure Received → Review Inventor Status → Review Funding Source →
  Review Resource Utilization → Determine Ownership → Execute Agreements
  Outcomes: University / Inventor / Joint / Sponsored Research Ownership

Workflow 3 — Patent Filing:
  Positive Evaluation → Filing Approval → Patent Drafting →
  Inventor Review → Application Submission → Patent Prosecution →
  Patent Grant / Closure

Workflow 4 — Commercialization:
  Protected IP → Market Assessment → Industry Engagement →
  Licensing/Startup Decision → Agreement Execution → Revenue Generation

Workflow 5 — Revenue Distribution:
  Revenue Received → Verify Revenue Source → Calculate Distribution Shares →
  Approval → Distribution to Beneficiaries → Record Maintenance

Implementation:
  - Laravel Events + Listeners for state transitions
  - Laravel Jobs + Queue for email notifications (non-blocking)
  - Workflow timeline visible on each Disclosure/Patent detail page

Key files:
  app/Models/WorkflowStep.php
  app/Services/WorkflowService.php
  app/Jobs/SendWorkflowNotification.php
  app/Events/WorkflowStepCompleted.php

NON-FUNCTIONAL REQUIREMENTS
================================================================================
- HTTPS/SSL enforced in production
- RBAC enforced on every portal route via middleware
- Audit logs for all data-changing operations (automatic via Model observers)
- Automated daily database backups (laravel-backup package)
- Mobile responsive at all screen sizes
- Optimized for low-bandwidth (lazy-load images, minimal JS, Vite bundling)
- TTO staff can operate system fully independently (CMS for public content)
- Deliverables: source code, database dump, user manuals, training materials
- Minimum 6 months post-deployment technical support
